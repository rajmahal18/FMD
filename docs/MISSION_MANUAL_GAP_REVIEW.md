# Mission manual / app gap review

Reviewed 2026-11-03 against the current repository and a read-only snapshot of the live **Operation: Classified — The Ultimate Mission** configuration. The event was Preparing during review. PDF page numbers below refer to the nine physical PDF pages, not the printed footer numbers.

Source: `FMD-TBA-2026-OPERATION-CLASSIFIED-MISSION-MANUAL-11032026.pdf` (2026-11-03 version). The manual is comparison material; it is not authorization to override the user's newer instructions or change live settings.

## Setup and supporting gaps

- **Judging contests are not configured live.** There are zero live JudgingContest records. The app already has suitable presets for Banner (30/30/20/20), Chant (30/30/20/20), Gala (30/30/20/20), and Best Squad Look (40/30/30), matching PDF 5 and 9. It also has separate Male/Female Agent of the Night presets, but the manual only names those awards and does not define their criteria. Create contests, select all entrants, and assign judges after confirming the policy. This is primarily setup work, separate from the missing overtime and overall-score integration.
- **Station metadata is incomplete live.** Six of seven stations have no required-player count and no brain/brawn ratings. Fragments of Memory is configured for 15 players, brain 5 and brawn 0. Without counts, the current selection flow requires at least one player rather than an exact station count. PDF 6 refers to brain/brawn ratings but does not supply all station values or player counts; obtain these from the approved station map/posters. The UI support already exists.
- **The program needs reconciliation.** The live program says 15 minutes per squad for the Gala, while PDF 8 allocates ten minutes total: three minutes combined setup/cleanup and seven minutes performance. PDF 2 lists briefing at 16:30, while the app program starts the briefing block at 16:00. The app's race starts at 05:30 after a 05:00 warm-up, while the manual describes Spy Chase 05:00–09:00. Confirm whether that operation window includes warm-up. Banner has a 45-minute manual activity inside a live one-hour program block; this may include setup, so it is not necessarily a contradiction. Event start/end dates are currently unset, although program dates exist. The extra November 4 forum day is not inherently a mismatch with a manual covering the November 5–6 team-building segment.
- **Special-award policy is unfinished.** Showstealer exists as a disabled one-choice participant vote. No Agent Contact/Congeniality policy is configured. Cornerstone has no dedicated policy/workflow. PDF 3 names these awards without explaining eligibility, judging/voting method, contact rules, or ties. They are policy decisions, not permission to invent mechanics. Best Squad Look must remain outside the overall championship.
- **One-phone operation needs explicit handling.** PDF 6 allows only one squad phone, surrendered at the station. Captain-led race operation fits one phone while travelling; individual accounts, Agent Contact scanning and individual voting should not be assumed available to every player during that restricted period. Agent Contact currently only accepts collection while the race is Live, so a post-race contact window would also need an explicit policy/implementation change. The manual itself does not specify when/how Congeniality is collected.
- **Tactical map/manual access is optional support work.** The app has station names, locations, availability and ratings, but no dedicated tactical-map display. A static approved map/manual could be useful; GPS tracking is neither needed nor implied by the manual.
- **Award presentation can be improved later.** The PDF gives official placement titles such as Prime Operative and Elite Operative. Current results primarily use generic placements; those titles can be added as event-specific presentation after the scoring is correct.

## Existing support to retain

- Five live squads currently have 18 assigned active participants each, consistent with the manual's approximately 18–19.
- Free-roam station selection, optional assigned/randomized first stops, station occupancy/capacity, queues and code/QR verification exist. The current live route is Free roam and assigned to all five teams. Requiring a route definition to identify eligible stations is a UX issue, not proof that station order is fixed.
- Captain-selected lineups, individual played/team-explored histories, handler timer/penalty/finish/confirmation controls and audited corrections already exist.
- Timed instruction reading is supported by the current user-approved flow. Handler-enforced physical retries can occur while the challenge remains Active, without pausing its timer.
- Raw station elapsed time and time penalties are preserved separately. Station time-limit UI currently warns; it does not automatically finish at the limit. Confirm how handlers should record cutoff/unfinished-item penalties rather than assuming that warning implements every timeout rule.
- Judging criteria, assigned judges, private drafts, review/submission and publication snapshots exist. Special judged awards can remain separate from race scores.
- Physical banner shifts, relay equipment, cipher solutions, chant delivery, phone surrender, attire, holding-area discipline and physical defusal remain handler-run activities. They do not require building a generic game engine.

## Decisions before implementation

1. Is this PDF the winning rulebook where it conflicts with the latest captain-start flow and the existing live weights?
2. What are the station tie/incomplete rules and the exact Spy Chase-to-100 normalization formula?
3. What is the Final Station countdown duration/start policy, and how do late squads join?
4. What are the official overtime deduction application/floor and special-award policies?

Recommended work order: confirm policies → correct station/race and overall scoring → implement Final Station eligibility/countdown/outcomes → align arrival timing and incomplete-squad handling → add judged overtime deductions → configure contests/metadata/program → rehearse the full event.
